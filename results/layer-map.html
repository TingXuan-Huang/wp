Which layers did the edits touch, and what was each one testing?

Qwen3.5-0.8B has 24 layers, numbered 0 to 23. Each layer has an attention block and an MLP. Layers 3, 7, 11, 15, 19 and 23 use full attention; the others use linear attention (Gated DeltaNet). Every chart below runs across those 24 layers, input side on the left.

The results folder holds two kinds of layer evidence: which weights each run changed (measured in E2), and where each agent's own tests placed the behaviour (from its written summary). It holds no raw activation recordings, so "active" here means located by the agent's probes, attribution, steering or patching. Companion to the results overview.

Each task came down to one or two concepts, and each concept has a home in the network.

A number is how many of the six agent runs for that task changed weights in that layer. The tick marks under the strip are the full-attention layers. Click a run to open its account further down.

Every run, layer by layer. Click a row for what the agent tested.

Gain is the test-set gain from E1, in points. Random edits are left out: each one changes the same tensors as the basic agent run it is matched to.
