Can an agent fix a model by editing its weights?

A Claude agent (claude-opus-5-5, 25 forward passes and 150 turns per run) edited the weights of Qwen3.5-0.8B to fix one behaviour at a time. It was compared with fine-tuning, a random edit of about the same size, and direction removal. All numbers are edited minus original, in percentage points.

The best agent edit lifts every task by 22 to 90 points on the test set.

Test accuracy of the original model and after the best agent edit for that task (the one with the highest gain on the select split).

E1 · does the edit work?

The agent matches or beats fine-tuning on loops, markdown and facts. Fine-tuning wins on addition. Random edits do nothing.

Bars are the mean test-set gain per method, dots are single runs (three per agent and random condition, two fine-tunes, one direction removal). "Interp" is the agent with interpretability tools added.

E2 · what did the edits change?

Several agent edits are tiny. One neuron (1,024 weights) is worth +69 points on markdown.

Each mark is one run: how many weights it changed against its gain on the select split. Fine-tunes change 3 to 49 million weights. Loops runs were scored on 100 problems, so their gains are uncertain by several points.

On loops, agent edits keep their gain when most of the edit is pruned away. Fine-tunes lose it at once.

Gain on the select split as only the strongest share of each edit's changed columns is kept. The four large loops edits are shown (28 to 49 million weights each).

E3 · what else does each edit affect?

Agent edits stay on their own task. Fine-tunes leak into the others.

Each row is one edit scored on every test set. Off their own task the four agent edits move other tasks by 3.4 points or less, except markdown's +11.8 on addition. Facts has 70 test items, so one item is 1.4 points.
